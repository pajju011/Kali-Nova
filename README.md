# Kali-Nova

Kalinova is a PyQt6 desktop control center for ethical security testing workflows on Kali Linux.

The application source code, tools, modules, and detailed documentation are located in the [`kalinova/`](file:///c:/Users/ASUS/Desktop/Kali-Nova/kalinova) folder.

For full project documentation, architecture details, execution instructions, and AI collaboration protocols, please refer to:
👉 **[kalinova/README.md](file:///c:/Users/ASUS/Desktop/Kali-Nova/kalinova/README.md)**

## Quick Start

```bash
cd kalinova
python -m venv venv
venv\Scripts\activate   # On Windows
source venv/bin/activate # On Linux/macOS
pip install PyQt6 reportlab pytest
python main.py
```
