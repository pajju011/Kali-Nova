# Kali-Nova Project Rules

- **Categorization Rule**: Always place new security tools strictly into their matching category UI module (`web_page.py`, `network_page.py`, `auth_page.py`, `recon_page.py`, `reports_page.py`). If a new tool does not fit into any existing category, create a new category page UI module and register it in `main_window.py` and `workspace.py`.
